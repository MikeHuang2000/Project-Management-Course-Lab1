## 3 估算依据（Basis of Estimates）

- **基本规则**：自下而上，每个 WBS 任务按角色给"人日 × 日薪"；单角色单任务时人日等于任务工期。
- **假设**：日薪为虚拟值，仅用于本实验口径一致；不折算 token 成本；人日由任务工期与失败率/返工折算（公式见 `08-cost.md` §4）。
- **数据源**：任务与工期 `plan/tasks.csv`，费率 `plan/rates.csv`，实际人日 `plan/actuals.csv`。
- **估算类型**：项目早期为预算估算（用于立项与资金计划），基线冻结后按确定性估算使用。
- **应急储备**：¥2,000 对应已识别高风险 R1–R8（见 `09-risk-quality.md`），按实际返工/补测人日据实动用，不预设单项金额。
- **管理储备**：¥1,900 = 客户上限 ¥19,700 − 批准预算 ¥17,800，应对未知风险，动用须 CCB 批准。

## 7 控制成本与 EVM

- 三个基础值：PV（计划工作的批准预算）、EV（完成工作的批准预算）、AC（实际总成本）。
- 指标：CV = EV − AC、SV = EV − PV、CPI = EV/AC、SPI = EV/PV。
- 预测：偏差延续用 `EAC = BAC/CPI`；一次性偏差用 `EAC = AC + (BAC − EV)`；`ETC = EAC − AC`、`TCPI = (BAC − EV)/(BAC − AC)`、`VAC = BAC − EAC`。两种 EAC 都算，最终取舍在监控报告中说明（见 `stage4-monitor.md` §3）。
- 现状：最终 EV 15,800、AC 17,974.90、CV −2,174.90、CPI 0.879、SPI 1.000；二期 PV=EV=AC=1,475、CPI=SPI=1.00，单列不计入一期。
